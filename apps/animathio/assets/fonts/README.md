# Embedded UI fonts

These fonts are loaded into GPUI at startup, so the editor does not depend on
fonts installed on the host. The committed bytes also ship in packaged builds.

- Inter Variable: [rsms/inter](https://github.com/rsms/inter),
  `docs/font-files/InterVariable.ttf`; license: `Inter-OFL.txt`.
- JetBrains Mono Regular: [JetBrains/JetBrainsMono](https://github.com/JetBrains/JetBrainsMono),
  `fonts/ttf/JetBrainsMono-Regular.ttf`; license: `JetBrainsMono-OFL.txt`.

Both are redistributed unmodified under the SIL Open Font License 1.1. The
license files include their upstream copyright notices. Retrieved 2026-11-13.
