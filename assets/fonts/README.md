# Embedded font

`DejaVuSans.ttf` is the unmodified DejaVu Sans 2.37 font from the DejaVu project
(<https://dejavu-fonts.github.io/>), copied from the Arch Linux `ttf-dejavu` package.
The accompanying `LICENSE-DejaVu.txt` contains the Bitstream Vera/Arev permissions
and the package's license notices. It is embedded for repeatable text shaping;
system font discovery is disabled. Unsupported characters use the font's missing
glyph rather than machine-dependent fallback fonts.
